## 배포 서버 실행 시

1. 관리자 로그인
   - 아이디: admin / 비밀번호: 1234
   - 대시보드 확인 가능
   - 곡 추가 시 'M3 추천 플레이리스트'에 추가 확인

2. 회원 로그인
   - 기능 사용을 위해서는 로그인 필수
   - 회원가입 후 로그인 (아이디, 닉네임 중복 불가)
   - 유튜브 링크를 추가하고 태그를 고르거나 직접 입력하면 '모두의 플레이리스트'에 추가
   - 좋아요 기능

3. 마이페이지
   - 닉네임, 비밀번호 변경 가능
   - 닉네임 변경 시, 홈에서 올린이 이름 변경 확인 가능
   - 등록한 곡과 찜한 곡 모아보기
   - 찜한 곡은 하트를 다시 눌러 취소 가능
   - 등록한 곡 삭제 가능

## 소스 파일 실행 시

※ API 경로가 배포 서버로 설정되어 있으므로 로컬 실행 시 백엔드 없이 프론트만 실행해도 동작함

- 프론트엔드
  cd frontend -> npm run dev

- 백엔드 
  MusicMoodApplication.java 실행
